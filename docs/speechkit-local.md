# Короткая проба голоса Александра

Это локальная подготовка по [issue #4](https://github.com/Filigor123/TV-Quiz/issues/4).
Игровой голос, таймеры, очки и подключение игроков пока не меняются.
Реального синтеза и прослушивания на этом этапе не было.

## Сейчас: бесплатно посмотреть оценку

Откройте обычный терминал Windows в папке **этой ветки проекта** и выполните:

```bat
scripts\speechkit.cmd
```

Команда не использует сеть, не просит ключ и не создаёт файлы. Она покажет:

- голос `alexander`, амплуа `neutral`, обычная скорость;
- одну реплику из issue #4 про слово «кринж», 145 символов с пробелами;
- один запрос модели `general` API v3: ориентир **0,1626 ₽ с НДС**.

Это [официальный рублёвый тариф](https://aistudio.yandex.ru/ru/docs/speechkit/pricing),
проверенный 17.11.2026, а не бесплатный лимит. Грант, скидка и остаток средств
этим инструментом не проверяются. Перед запросом сверьте цену и валюту аккаунта.
Регистрация и создание API-ключа сами по себе не означают согласия на расходы.

Запускатель использует уже имеющийся Python из Codex, иначе `py -3`.
Вне этой машины нужен Python 3.10+; дополнительных пакетов и FFmpeg не требуется.
Эквивалентная команда: `python -B -X utf8 scripts/speechkit.py`.

## После отдельного разрешения на платную пробу

Эту команду запускает сам пользователь в обычном локальном терминале:

```bat
scripts\speechkit.cmd --synthesize
```

Сначала появятся объём и цена. Введите `СИНТЕЗ`, только если разрешаете указанные
расходы; пустой Enter отменит запуск. Затем в строку **«API-ключ (ввод скрыт…)»**
вставьте секретную часть ключа и нажмите Enter. Символы не отображаются.
Не вставляйте ключ в чат, команду, JSON или файл проекта.

Ключ читается через `getpass` на каждый запуск и живёт только в памяти процесса.
Он не передаётся через аргументы или переменные окружения, не записывается в
историю команд, кеш или журналы инструмента. Если скрытый ввод недоступен,
программа завершится вместо перехода к видимому вводу. Не используйте запись
терминальной сессии или отладчик; гарантированного стирания строк из памяти Python нет.
Окно ввода инструмент сам не открывает.

Требуется **API-ключ**, не IAM-токен, идентификатор ключа или JSON авторизованного
ключа. [Ключ из AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/get-api-key)
также принадлежит сервисному аккаунту: интерфейс может создать его автоматически.
У созданного вручную сервисного аккаунта проверьте роль `ai.speechkit-tts.user`
на каталог и область ключа `yc.ai.speechkitTts.execute` (либо включающую её).
Срок действия ключа должен быть действующим, платёжный аккаунт — активным.
Фактический доступ автоматически созданного аккаунта тоже стоит проверить.

Оба вида API-ключа используют `Authorization: Api-Key …`. В этом клиенте не нужен
ID каталога: для сервисного аккаунта используется его каталог, как указано в
[инструкции SpeechKit REST v3](https://aistudio.yandex.ru/ru/docs/speechkit/tts/api/tts-v3-rest).
Новая общая страница аутентификации упоминает `x-folder-id` для v3; при диагностике
учитывайте отличие пользовательского IAM-токена от используемого здесь API-ключа.

## Запись и повторное использование

После успешной пробы откройте WAV в `.local-tools/speechkit/` любым аудиоплеером.
Оцените естественность, слово «кринж», буквы вариантов, паузы и темп.
Повторный запуск с тем же текстом/параметрами использует проверенную запись без
сети, оплаты и ввода ключа. Каталог исключён из git.

Имена WAV — SHA-256 от текста, параметров и версии API. Рядом лежит JSON с
параметрами и контрольной суммой аудио, без ключа. `manifest.json` связывает
понятные ID реплик с файлами. Изменение текста/настроек создаёт новый ключ кеша;
повреждение старой записи останавливает запуск, а не вызывает повторную оплату.

Для будущего пакета создайте UTF-8 JSON по образцу `content/speechkit/sample.json`:

```json
{"clips": [{"id": "intro", "text": "Телефоны готовы? Отлично."}]}
```

Сначала оценка: `scripts\speechkit.cmd --manifest путь-к-пакету.json`.
Каждая реплика — 1–249 символов; длинные нужно заранее разделить по смыслу.
Ограничение сервиса — также 24 секунды: число символов само по себе не гарантирует
успех. Пустые/длинные тексты отклоняются локально, `unsafeMode` выключен.
Одинаковые тексты с одинаковыми настройками оплачиваются один раз в этом кеше.

Платная подготовка пакета требует отдельного разрешения: добавьте `--synthesize`
и согласованный предел `--max-cost-rub`, например `1.00`. По умолчанию предел
равен цене **одной** пробы. Это предел по справочной оценке, не настройка бюджета
в Яндексе. Изменённый текст или удалённый кеш может потребовать новой оплаты.

После одобрения голоса можно отдельным PR скопировать выбранные WAV и манифест
в публичные assets и подключить воспроизведение на ТВ. При игре будут загружаться
готовые файлы GitHub Pages; запросов синтеза и ключа в браузере не будет.
Текущий инструмент сам ничего не публикует и не озвучивает банк вопросов.

## Ошибки и проверки

401: проверьте секретную часть и срок ключа. 403: роль, область действия,
платёжный аккаунт. 400: текст/параметры и предел 24 секунд. 429: квота запросов.
Тела ответов и заголовки с ключом не печатаются. Перенаправления запрещены,
HTTPS проверяется обычным TLS-клиентом Python. Автоматических повторов нет.

После таймаута/обрыва/ошибки записи проверьте потребление в Яндексе перед новым
запуском: сервис мог успеть выполнить оплачиваемый запрос. Успешные предыдущие
записи пакета сохраняются. При неполной паре WAV/JSON сначала проверьте файлы;
удалять их для повторного синтеза можно только осознанно. Одновременные запуски
в один кеш блокируются. После аварийного завершения удалите `.synthesis.lock`
лишь убедившись, что другого генератора нет.

Offline-проверки (сетевой транспорт и ввод ключа заменены заглушками):

```bat
python -B -X utf8 -m unittest discover -s scripts -p test_speechkit.py -v
```

Проверяются отсутствие сети/ввода/записи при оценке, подтверждение расходов,
предел цены, скрытый ввод и отказ от эха, v3-запрос, поток JSON/base64 → WAV,
ошибки без утечки ключа/повторов, кеш, дедупликация, остановка частичного пакета
и блокировка параллельного запуска. Живой API, реальные права ключа, скрытый ввод
в пользовательском терминале и качество на слух требуют отдельной пробы.
