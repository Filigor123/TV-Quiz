# Выбор квизов с пульта

Первый экран — каталог с обложками. Главная и лобби без звука. Музыка,
эффекты и голос включаются после «Начать викторину»; настроек звука нет
(уточнение Игоря от 16.11.2026). Громкость меняется средствами телевизора.
Если голос недоступен, кнопка «Продолжить без голоса» доступна с пульта.

| Экран | Управление |
| --- | --- |
| Каталог | ← → квизы внутри ряда; ↑ ↓ темы; OK выбирает |
| Параметры квиза | ↑ ↓ перейти к параметру; ← → изменить значение; OK дальше или выполнить кнопку |
| Лобби | ↑ ↓ выбрать доступную кнопку; OK начать, когда все готовы |
| Назад | К предыдущему экрану; из лобби закрывает комнату и возвращает к параметрам |

Фокус устанавливается сразу, недоступные карточки пропускаются. При возврате
сохраняются выбранная карточка и прокрутка. Пока игра идёт, «Назад» не обрывает
партию. Редактор собственного вопроса доступен по `index.html#editor`, вне
обычного пути запуска. «Кто ближе?» — самостоятельная карточка в «Эрудиции»:
10 подготовленных числовых заданий, до конца таймера ответы скрыты,
каждый из ближайших игроков получает одно очко. Существующая механика очков
не изменена. При выборе 15 используются 10 уникальных заданий.

## LG и ограничения браузера

Обработаны `ArrowLeft/Up/Right/Down`, Enter, OK/Select, Escape/BrowserBack,
числовые коды стрелок 37–40, OK 13 и «Назад» LG 461. Дополнительно принимаются
23 и 10009. Непечатаемый Backspace возвращает назад; ввод в редакторе не ломается.
History API поддерживает возврат, когда браузер обрабатывает «Назад» сам.

Коды LG и поведение Magic Remote сверены с официальными документами:
[Magic Remote](https://webostv.developer.lge.com/develop/guides/magic-remote),
[Back Button / History API](https://webostv.developer.lge.com/develop/guides/back-button).
По руководству LG нажатие стрелки переключает пульт из указателя в кнопочный режим.
Это документация платформы; поведение конкретного встроенного браузера требует
проверки. Сайт не управляет системным указателем, Home, громкостью и долгим Back.
Модель и год LG не установлены: проверка настоящим пультом **не выполнена**.

## Проверки 16.11.2026

- В опубликованном main (`0c6dd7f`) Edge показал 59 карточек без ошибок JS.
  Исчезновение всех карточек на телевизоре не воспроизведено. Убрана ранняя
  инициализация селектора голосов, которая раньше выполнялась до каталога;
  вместо пустого места предусмотрено сообщение об ошибке загрузки.
- `node scripts/test_tv_navigation.cjs`: стартовый фокус, оба направления
  прокрутки, пропуск недоступных карточек, коды LG, параметры, история/возврат,
  закрытие старой комнаты, два имитированных клиента, запуск, звук, скрытие
  ответа, раскрытие и ничья в «Кто ближе?». Нет обязательной мыши/Tab на пути
  от каталога до запуска. Проверены недоступные Speech API и localStorage.
- Разметка 1920×1080 и 3840×2160: три полных ряда; 390×844: без горизонтального
  переполнения страницы. [Стартовый экран 1920×1080](tv-catalog-1920.png).
- Дополнительно **реальный PeerJS** без подмены сети: ведущий и два отдельных
  браузерных клиента 390×844, QR, подключение, готовность, запуск с клавиатуры,
  ответы и раскрытие. В headless Edge голос недоступен: продолжение с пульта
  проверено. Прослушивание звука человеком и игра на физических устройствах
  не выполнялись.
- Существующие validators: audio sequence, wager, media integration, audio quiz,
  fact quiz; синтаксис и `git diff --check`.

Для браузерного теста нужны Node.js, Playwright и установленный Edge.
Другой Chromium можно выбрать переменной `TV_TEST_BROWSER` (канал Playwright).
Скриншоты по умолчанию пишутся во временную папку `tv-quiz-test-artifacts`;
`TV_TEST_ARTIFACTS` меняет каталог. Сеть PeerJS в этом воспроизводимом тесте
имитируется явно; успешный результат не доказывает доступность внешнего сервера.

стрелку, выбрать несколько квизов, вернуться, изменить параметры, подключить
телефоны и начать. Проверить голос/музыку и рамку выделения с обычного расстояния.
