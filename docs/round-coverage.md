# Три раунда: состав и ограничения

Срез ветки codex/three-round-games. Все 60 доступных карточек имеют три непустых раунда. Числа — фактическое число вопросов раундов 1 / 2 / 3. Финал выбирается из расширенного банка: повторная игра меняет состав. Цель полного набора — 10 / 10 / 10; 25–35 минут — ориентир #4, длительность не измерена.
