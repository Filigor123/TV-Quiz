## Открыть редакторское превью
Из корня репозитория: `python -m http.server 8000`. Открыть `http://localhost:8000/content/evening-2026-11-14/review.html`.
Превью не зависит от CDN и не обращается к PeerJS. Оно не является игровой ссылкой и не публикуется автоматически.
Ответы спрятаны в details только для удобства редактора; в исходнике они есть. Не использовать этот HTML как клиент игрока.

3. Объединить с актуальным банком, включая ещё не слитый банк 300, по ID и смыслу. НЕ заменять questions.js этими 30 записями. 4. Текстовые категории/темы/уровни взяты из существующего банка. Это не равномерное заполнение всех 30 комбинаций до 15; показывать фактическую доступность.
5. media.json → ready использует форму PR #15: prompt, options, answer, acceptedAnswers, media.src. Шесть SVG уже в assets/quiz-media. 7. После подключения проверить файл → загрузку → показ/воспроизведение → скрытие правильного ответа до раскрытия → начисление. При ошибке загрузки дать пропуск; не зависать на вопросе. Фон во время ролика/музыки ставить на паузу. Эти данные не меняют правила раундов/ставки.
8. Сначала переиспользовать готовые 45 заданий PR #15; новые источники расширяют подборку и не требуют переписывать существующий пакет. Инструменты локальной нарезки не нужны для подключения шести SVG.
9. Сохранить изменения через commit/push/PR. Слияние по действующим разрешениям проекта; подготовка контента сама по себе не доказывает игровую проверку или публикацию.

## Источники и статус
У каждой текстовой записи sourceUrls и дата проверки 14.11.2026. Использованы официальные QueenOnline, Мосфильм, Volkswagen Commercial Vehicles, NASA, NIST, NOAA, UNESCO и NPS. Вопросы и объяснения сформулированы заново, тексты страниц не копируются.
NASA/Queen/Mosfilm источники прочитаны через поиск и страницы; для кандидатов sourceCheck различает открытый источник, поисковый индекс и ошибку прямого открытия. На странице Мосфильма «Кин-дза-дза!» есть неточный синопсис о названии планеты; эта формулировка НЕ использована в вопросах.
Цезий-133, единицы СИ и длительности обращения — устойчивые факты; переменные количества спутников не использованы.
SVG — собственные точные геометрические схемы без сторонних изображений. Ответы не написаны в SVG или именах файлов. Условия задач и описательные alt нужны для доступности; по ним задача остаётся решаемой, ответа напрямую нет.
Сторонние видео не скачаны, не просмотрены и не нарезаны в этой поставке. Для Radio Ga Ga поиском подтверждены название и YouTube URL, но прямое открытие завершилось ошибкой. Для страниц 1tv прямое открытие также недоступно. Таймкоды необходимо выбрать на реально полученной записи; длительность 6–10 секунд — цель, а не измеренный фрагмент. Распространение сторонних записей отдельно не проверено.

## Проверки
Запуск из корня: `python scripts/validate_evening_pack.py`.
Для точной сверки с имеющимся банком: `python scripts/validate_evening_pack.py --baseline /path/to/questions.js`.
Проверяются ID, обязательные значения, четыре разных ответа, индексы, URL, категории/темы, локальные SVG, размеры/хеши и отсутствие source-only в ready. Сравнение с baseline ищет нормализованные точные тексты; смысловую уникальность автомат не доказывает.
Синтаксис превью, математические решения и визуальная раскладка проверяются отдельно. Реальная партия ТВ/телефоны не проводилась.
