## Игровое поведение

- Раунд 1: выбрать передачу или исполнителя после полного короткого фрагмента.
- Раунд 2: написать ответ после фрагмента. Нормализация учитывает регистр, `ё/е`, пунктуацию и заранее заданные варианты. Дополнительно принимается одна вставка, пропуск, замена или перестановка соседних букв для ответа длиной от пяти знаков; для ответов от 12 знаков допускаются до двух таких правок.
- Раунд 3: выбор по первым трём секундам фрагмента; после раскрытия ведущий может воспроизвести подготовленный отрывок целиком.
- Во время записи музыка ведущего выключается. Запись проигрывается только на экране ведущего; телефоны получают только формы ответа.
- Ставка из #6 доступна только в раунде 2, один раз на игрока: +2 за правильный ответ, −1 за неправильный. В остальных раундах обычный счёт.
- Ошибка загрузки записи пропускает вопрос без очков.

Исходные сведения об источниках, подготовке клипов и статусе прав: PR #15, `content/media-pack/README.md` и `content/media-pack/manifest.json` в ветке `content/media-pack-13`.
