# Пилот по аббревиатурам и «Правда или вымысел»

Это небольшой контентный пилот 3×5 для оценки механик из issue #5, не полный набор на 3×10. Вопросы сформулированы самостоятельно. Публичный Telegram-анонс VEKSHITO с названием «Расшифруй аббревиатуру» и ссылкой на выпуск изучен как источник формата; сам выпуск не просмотрен, таймкоды не получены, и вопросы из него здесь не воспроизводятся:

- [публичный Telegram-канал, запись «В аббревиатуры сыграли»](https://t.me/s/dmitryvekshito?after=255)
- [выпуск на YouTube](https://youtu.be/6ngcb9zLKlU)

Факты ниже проверялись по независимым справочным и официальным источникам, указанным у каждого задания в `facts-quiz.js`. Это не утверждение, что автор VEKSHITO использовал эти задания.

## Раунды

1. Контекстный выбор из четырёх расшифровок.
2. Свободный ответ с нормализацией регистра, пробелов, пунктуации и заранее перечисленных вариантов.
3. Два ответа — «Правда» / «Вымысел», одна проверяемая часть факта и пояснение после раскрытия.

Вопросы и определения имеют стабильные ID; каждый факт имеет прямой источник. В третьем раунде используется уже существующее отображение двух вариантов выбора. Новая система подсчёта не вводится: верный ответ даёт 1 очко, неверный — 0. Игровые ответы остаются скрытыми до раскрытия; ставка второго раунда действует по отдельному PR #21.
