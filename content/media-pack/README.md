# Медиапакет для Валеры · задача #13

## Сверка источников 21.11.2026

В готовой части 45 заданий и ещё 6 собственных звуков сопровождения. Для переноса в обычные квизы проверены шесть флагов `geo-01`–`geo-06` и снимок `science-i01`. [Flagpedia](https://flagpedia.net/terms) указывает, что изображения флагов находятся в общественном достоянии. Карточка [PIA01492](https://science.nasa.gov/photojournal/neptune-full-disk-view/) указывает авторство NASA/JPL. Снимок используется с атрибуцией по [политике использования изображений JPL](https://www.jpl.nasa.gov/jpl-image-use-policy/). Ещё два изображения и шесть звуков сопровождения изготовлены для проекта.

Для 36 старых сторонних записей и кадров право на распространение по-прежнему не подтверждено. В их числе 12 музыкальных нарезок из магазинных превью. [Правила Apple](https://performance-partners.apple.com/search-api) ограничивают такие превью потоковым воспроизведением в рамках продвижения самой записи. Для включения этих фрагментов в обычные квизы нужны отдельные разрешения или замена. В обновлении обычных музыкальных и кинофиналов используются записи из [пакета CC BY](../../media-credits.html).

Подготовлено 14 ноября 2026. Пакет контента и реальных файлов; игровой код не изменён. Игорь поручил самостоятельно подготовить материалы и подключить их для последующей проверки в игре. Не требовать от него вручную собирать файлы.

## Файлы и запуск просмотра

- `manifest.json`: ответы, четыре варианта, допустимые написания, источники, реальные границы исходников, статус, размеры и SHA256. Ответ намеренно указан первым в редакторском JSON; в игре обязательно перемешать варианты и пересчитать индекс.
- `../../assets/quiz-media/`: 51 готовый файл. Короткие аудио MP3, видео MP4 H.264/AAC, картинки JPG и собственные схемы SVG. Полные исходные фильмы/песни в репозиторий не добавлялись.
- `review.html`: отдельное редакторское превью, не игровой экран и не доказательство подключения к сайту.
- Из корня репозитория: `python -m http.server 8000`; открыть `http://localhost:8000/content/media-pack/review.html`.
- Проверка: `python scripts/validate_media_pack.py`. Повторное изготовление одного прямого источника: `python scripts/prepare_quiz_media.py music-001 --write`; без `--write` только план. Собственные фон/сигналы: `python scripts/build_quiz_audio.py`. После изменения файлов обновить хеши и длительности в манифесте.

## Что проверено

Идентификаторы, четыре разных варианта, присутствие ответа и допустимых форм, существование и размеры всех файлов, SHA256, открытие растров Pillow, XML SVG и полное декодирование FFmpeg всех аудио/видео. Изображения кино просмотрены на контактном листе: семь кадров без названия фильма. Восьмая картинка «Мимино» оказалась афишей с названием и удалена; запись отмечена `rejected_asset`. Один кадр видео просмотрен: сцена с персонажами на стадионе.

Не выполнены: прослушивание аудио человеком, оценка узнаваемости всех нарезок, полный просмотр видео, проигрывание в игровом движке, партия на ТВ и телефонах, полная проверка условий распространения. `file_prepared` означает технически изготовленный файл, а не редакторски утверждённый вопрос. Исходная идентификация аудио взята из метаданных страницы/провайдера и может требовать правки после прослушивания. Не заявлять эти проверки выполненными.

Перед случайной выдачей проверить, что файл соответствует источнику, нет произнесённого названия-ответа и прямых визуальных подсказок. 4. Первый пилот может быть меньше 30 вопросов; честно показывать доступное число. Для свободного ввода использовать acceptedAnswers с нормализацией регистра/ё/пробелов и проверяемыми опечатками. ## Источники и изготовление

Музыка: точные исполнители и названия выбраны из реального ответа iTunes Search API. Нарезка 0–10 секунд магазинного превью: это не первые ноты исходной песни. Нельзя выдавать эти фрагменты за интро. Не выбирать ремикс/кавер при замене записи; лицензия на повторное распространение превью не подтверждена.

Телезаставки и мемные звуки: прямые MP3 со страниц zvukipro/promosounds; страницы и прямые URL записаны по каждому вопросу. Зов джунглей особенно проверить на произнесённое название и при необходимости сдвинуть границы. Короткий сигнал может быть короче 8 секунд — не дополнять тишиной.

Кино: семь JPG с официальных страниц Мосфильма, один 12-секундный отрывок (2–14 с) из официального короткого ролика «Куда пошёл?» на Rutube. Получение: yt-dlp для открытого ролика; затем FFmpeg. YouTube вернул метаданные, но не пригодный для скачивания формат: два пробных скачивания не удались. Не обходить DRM/платный доступ.

Мем-картинки: Imgflip API в этой среде вернул 403. Четыре шаблона удалось получить через другие открытые страницы: «Отвлёкшийся парень», «Две кнопки», Гарольд, «Женщина кричит на кота». Они просмотрены и не содержат ответов. Остальные четыре пока без файлов; API/Imgflip вернул 403, изображение альтернативного источника Дрейка не декодировалось. Русские мемы «Идущий к реке», «Наташа», «Рыбов» остаются отдельными кандидатами. Обложка Наташи найдена, но содержит готовый ответ, поэтому не включена как вопрос. Не подменять исходный мем случайной картинкой.

Автомобили/физика: собственные точные SVG-схемы (поршень и рычаг); автомобильное фото T4 пока требуется получить. География: шесть флагов flagcdn с отдельными sourcePage. Наука: радарная карта Венеры NASA/JPL, это не фото планеты в видимом свете.

Аудио: FFmpeg, удаление метаданных, ограничение длительности, loudnorm I=-18 LUFS / TP=-2 dB; нормализация в один проход. Собственный фон/эффекты синтезированы без чужих сэмплов и нормализованы до I=-22 / TP=-3. Возможны различия воспринимаемой громкости — прослушать на ТВ.

Открытые страницы и короткая длительность не означают разрешения. Статус источников записан честно; пользователь разрешил подготовку тестовых материалов в публичном GitHub. Перед широким запуском проверить основания распространения, указать авторство или заменить файл; это не причина превращать уже разрешённую подготовку в новую цепочку вопросов Игорю.
